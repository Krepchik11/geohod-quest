4 · Конструктор: дельта к новой модели GameStep

Существующий редактор страницы поддерживает только: текст + 1 изображение + следующая страница. Новая модель из SPEC требует значительно больше — текущий дизайн конструктора не способен создать ни один answer-шаг:

5 · Конфликты и решения, которые нужно принять

  1. 7 шаблонов против 4. Figma и старая система — 7 типов страниц; CONCEPT жёстко требует 4. Видео становится медиа-контентом внутри шаблона, «Поздравление» = «Продолжить»+terminal, «Видео маршрута» умирает. Подтвердить.
  2. Визуальный язык игрока ≠ визуальный язык сайта. Единственные артефакты квест-флоу (миниатюра шаблона, превью редактора) — винтажная «бумага»: крем #FCF3EA, шрифт Prata, коричневые чернила #3E2C2C, контурные кнопки. Сайт — синий #3B71FE + Inter. Это глобальный стиль плеера или арт-дирекшн конкретного квеста «Ирония судьбы»? От ответа зависит вся система шаблонов (и конструктор: появится ли выбор темы).
  3. Мультиязычность. Конструктор в Figma выбирает язык (EN/RU/SRB), v1 — только русский. Упрощаем дизайн или оставляем задел?
  4. Навигатор. SPEC допускает и переход в системные карты (maps://), и встроенную карту по данным бандла. Для офлайна это принципиально разные дизайны.
  5. Экономика нигде не визуализирована. Нет ни иконки монеты, ни баланса, ни рейтинга игрока — нужен микро-дизайн-язык монет (иконография, анимация, звук) с нуля.
  6. Две сущности отзывов. FeedbackReport (репорт ошибки, любая страница) и Review (оценка после финала) — в текущем дизайне существует только маркетплейс-отзыв. Нельзя смешивать UI.
  7. Статусы квеста. Старый селект «Опубликован/Проект/Тест» противоречит иммутабельным снапшотам: публикация — необратимое действие с версией, а не переключатель.
