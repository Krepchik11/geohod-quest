[Naive mutable or non-idemp migration state] → Mitigation: pure fn + pre-check mark (or natural_key on synth facts + "legacy_imported" note) + idemp like grants/facts; always recompute from marks + facts; TDD goldens RED assert re-run no change + no dupe.

[Audit diffs inaccurate or silent fail on real historical scalars vs synth] → Mitigation: pure projector compare (project_balance etc vs mock old); output human report for manual review only (no auto per TECH/PLAN); goldens TDD + manual "run on discovery exports + inspect report"; tasks require "audit pass on golden mock + note any real diff".

[Version publish mid-migration or concurrent attempt corrupts synth/historical] → Mitigation: synth targets historical frozen snaps (separate from live PublishedMeta); migration marks historical only; attempts bind to exact snap forever (manifest); new attempts on latest; pure/lock serializes like admin; goldens cover "publish after synth, stats separate".

[Measurement accuracy (real bundle with comics/audio/nav, ctor vel, corr rate, fb/abuse, player UX) unreliable post-MVP/manual] → Mitigation: explicit post-MVP + basic (goldens + validate est + facts fold for rates/fb/abuse + manual "time ctor add 4role step + gate", "play + note popup/nav/anim UX + 'Оставить отзыв'", "count corrs"); re-run adv on real exports; no auto claims; tasks enforce manual + "update 08 with measured sizes/rates".

[In-mem migration marks/data lose on restart (like facts/grants)] → Mitigation: explicit documented swap path (same as facts-sync/marketplace-grants/admin: "Future: trait ... Jsonl/Sqlite (no behavior change)"); player reconnect + facts re-append (idemp) + pure synth/audit/mark check gives identical; TDD unaffected; demo re-play easy; tasks require manual "restart + re-run migration verify same report/marks".

[Goldens drift or incomplete coverage for migration/measurement (historical mocks, bundle real assets, ctor vel, abuse)] → Mitigation: RED first in replay (failing asserts on synth/audit/mark/rates/bundle/fb before any phase4 code); extend happy+edges+grants+admin (already has feedback/nav/wrong/hint); backend tests inject same + assert; manual + gates enforce (incl "use real exported for bundle size dry-run"); prior fidelity preserved.

[Import/export roundtrip or strict validate fails on real legacy content or YAML] → Mitigation: strict via shared (goldens contract + validateForPublish); enhance stub reuses exact ctor load path; TDD RED on import golden + export roundtrip + validate gates; labels for YAML pref + .yaml accept; manual "import/export real from discovery + note"; no advanced parser (YAGNI).

[Scope creep to advanced migration/UI/meas/persist/full e2e] → Mitigation: explicit YAGNI + cuts in proposal/tasks; pre-impl grep gates (no "advanced|persist for mig|full yaml lib|real bundle packer|auto vel"); self-crit at end + tasks 20+ with reuse/small checks.

[Per-version analytics in ctor shows stale or incomplete for drafts vs published] → Mitigation: ctor surface for published snaps only (from goldens/PublishedMeta + fetch /admin stats); draft edits use live validate gates not analytics (per PLAN "surfaced"); reuse existing.
