КОНЦЕПТ

3 части:
- МАРКЕТ: поиск покупка гранты
- КВЕСТ: смартфон PWA игра
- БИЛД: админ конструктор только

Квест = линейная seq GameStep

GameStep:
- богатый контент главный (комикс на страницу: задача / персонаж / подсказка / атмосфера)
- правило завершения: физ (подтвердить перемещение+действие) | ответ (список совпадение)
- поддержка: подарок монет, стоимость подсказки, кнопка навигатора (кратчайший маршрут), бонус аним+голос

4 шаблона основной UI:
- первый экран
- задание без ответа (физ)
- задание с ответом
- продолжить

Доступ = пожизненный грант (оплата | купон% | бесплатно)

Игра = скачать снапшот, полный оффлайн, клиент валидирует по снапшоту

Монеты = зарабатывать на заданиях (подарки+бонусы из снапшота), тратить на подсказки (только попап ошибка), накапливать рейтинг

Прогресс = только неизменяемые факты. Проецировать состояние. Без мутаций.

Инварианты:
- попытка привязана к снапшоту при старте
- клиент единственный судья локально
- факты только append
- грант перед игрой/заработком
- заморозить всё при публикации
- линейно без ветвления v1

Старый bubble = мёртв. Разбросанные мутации. Нет версий. Нет оффлайн. Вырезать всё.
